# Travel_Planner
The Travel Planner App is a comprehensive solution designed to simplify and enhance the travel planning experience. It allows users to create, manage, and customize detailed itineraries, make and modify reservations, and generate reports in PDF or Excel formats. Integrated AI-powered suggestions provide personalized recommendations for destinations, activities, and accommodations using OpenAI and Google Location APIs. Real-time weather updates help users make informed decisions by displaying forecasts for their travel dates and destinations, including temperature, humidity, and conditions. This all-in-one platform ensures a smooth and informed travel experience from start to finish.
